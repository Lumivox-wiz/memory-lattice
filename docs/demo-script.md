# 30 秒 demo 录制脚本

> 目的：给 README 顶部、帖子首图、目录页提供一段能证明「会忘」的短录屏。
> 录制目标：**1280×720 或 1440×900**，时长 25–35 秒，**不要配旁白**（字幕贴在关键动作上）。

## 录制前准备（一次性）

1. **完全退出 DSH Desktop（含托盘）**，然后重新启动 —— bundle 是按 URL 缓存在内存里的，热重载换不掉。
2. 确认插件已装：
   ```powershell
   pwsh -File deploy.ps1 -SkipProfile
   ```
3. **准备一个有内容的库**：录屏里空库会让「审核中心 / 沉睡区 / 星云」全都没东西看。
   最省事的办法是先用日常对话聊几句（每轮对话都会被捕获进短期记忆），
   或者在**配置 → 导入 / 迁移**里导入一份示例数据。
4. 准备好一个**要问的问题**，答案在你的记忆里（例：「我之前说的部署端口是多少？」）。

## 窗口与画面准备

- DSH Desktop 窗口调到 **1280×720 以上**，左侧边栏展开（要露出 🧠 入口）。
- 浏览器/系统缩放 100%，别让文字糊。
- 关掉会弹窗的东西（更新提示、通知）。
- 录屏工具：OBS / ScreenToGif / Windows 录屏都行。**帧率 30 足够**，导出 mp4。

## 六镜分镜（照这个顺序，一镜约 4–6 秒）

### 镜 1 · 侧栏入口（约 3 秒）

- 画面：DSH Desktop 侧栏底部，鼠标移到 **🧠** 图标上。
- 字幕：`插件入口：侧栏底部 🧠`
- 要点：**先让观众知道这是个插件**，否则后面全是看不懂的面板。

### 镜 2 · 写入 → 审核（约 6 秒）

- 画面：切到 **审核** 选项卡，指出待审条目（带「待审」标记的那几条）。
- 动作：点其中一条的**批准**按钮，等它变成「生效」。
- 字幕：`长期写入停在审核中心 —— 模型不能自行批准`
- 要点：这是与同类记忆插件最本质的区别（它们多半直接写库），**一定要拍到「批准」这个动作**。

### 镜 3 · 召回（约 5 秒）

- 画面：回到对话输入框，问那个准备好的问题：
  > 我之前说的部署端口是多少？
- 动作：等回答出现；如果 UI 上有召回面板就把它露出来。
- 字幕：`命中即复习：召回一次 = 强化一次`
- 要点：让观众看到**记忆真的被用上了**，不是躺在库里。

### 镜 4 · 过期（约 5 秒）

- 画面：**记忆**选项卡，切到状态筛选「短期记忆」，展示一批带时间戳的条目。
- 字幕：`短期记忆 48h 自动过期`
- 要点：如果库里有明显更早日期的条目，指一下（可以说「这些是上周的，已过期」）。
- ⚠️ **不要在 demo 里真的等 48 小时**。用筛选器展示「沉睡/过期」状态的存量条目即可；
  如果库是空的，就用 **概览** 页的遗忘曲线代替这一镜。

### 镜 5 · 沉睡区（约 5 秒）

- 画面：**概览**页的遗忘曲线，或记忆页里状态为「沉睡」的条目，点一下**唤醒**按钮，
  状态变回「生效」。
- 字幕：`久不用 → 降权 → 沉睡（可一键唤醒，不删除）`
- 要点：强调**可恢复**，这是它和「定期删除」的区别。

### 镜 6 · 星云收尾（约 5 秒）

- 画面：**云图**选项卡，3D 星云自转；拖一下旋转，单击一个节点聚焦。
- 字幕：`记忆星云 · 纯 canvas 3D，零图表库依赖`
- 要点：视觉记忆点，留 2–3 秒让人看。

## 剪辑要点

- 镜头之间用**硬切**，别用花哨转场。
- 全程**不加旁白**，字幕足够。旁白要配时间轴、还要改语种，收益低。
- 总时长压在 **30 秒上下**；超过 40 秒完播率会明显掉。
- 首尾各留 0.5 秒静止，方便循环播放。

## 产出物

| 文件 | 用途 | 规格 |
| --- | --- | --- |
| `docs/demo.mp4` | README 顶部 / 帖子首图 | mp4（H.264），≤ 5MB，1280×720 |
| `docs/demo.gif` | 目录页 / 帖子内嵌 | gif，≤ 3MB（可只截其中 15 秒） |
| `docs/screenshots/demo-poster.png` | 没有视频时的封面图 | 1280×640（social preview 比例） |

压缩命令（装了 ffmpeg 的话）：

```bash
# 压到 5MB 以内
ffmpeg -i demo-raw.mp4 -vf "scale=1280:-2" -crf 30 -preset slow -movflags +faststart demo.mp4

# 转 gif（只取 15 秒，压色板）
ffmpeg -t 15 -i demo-raw.mp4 -vf "fps=12,scale=640:-1:flags=lanczos,split[a][b];[a]palettegen[p];[b][p]paletteuse" demo.gif
```

## 1280×640 social preview

GitHub 的 social preview（仓库首页右侧那张大图）可以在仓库设置里上传：

**Settings → General → Social preview → Upload an image**

自己生成的话（把星云截图裁成 1280×640，再叠一行标题）：

```bash
ffmpeg -i docs/screenshots/nebula.png -vf "scale=1280:640:force_original_aspect_ratio=increase,crop=1280:640" -frames:v 1 /tmp/preview.png
```

然后把标题文字压上去（可选，用任何图片工具都行）。建议压的字：

> **忆枢 memory-lattice** — a memory plugin that forgets on purpose

## 检查清单

录完过一遍：

- [ ] 6 镜都在，总时长 25–35 秒
- [ ] 观众能看清**审核中心 → 批准**这个动作
- [ ] 有一次**召回命中**的画面
- [ ] 有**过期 / 沉睡**的证据（曲线或状态筛选）
- [ ] 结尾是星云（视觉记忆点）
- [ ] 字幕无错别字，中英文一致
- [ ] mp4 ≤ 5MB，gif ≤ 3MB
- [ ] 静音状态下能看懂（没有声轨也能理解）
